# Ecclesia — the built site

This repository holds the published build of Ecclesia, a theological library with original-language reading
(Biblical Hebrew, Aramaic, Greek and Latin). It is served at https://rookie2401.github.io/ . The source is kept elsewhere.

## Sources, credits and licences

- **Library texts** (`/library/`): each edition's credit and licence are in its `manifest.json` and shown in the catalogue at
  `/library/index.html`. Every stored edition is public domain, CC0, or CC BY-SA 4.0.
- **Language data** (`/lingua/`): see `/lingua/NOTICE.txt`. Some of it comes from openly licensed datasets (CC BY, CC BY-SA),
  used with credit; they are not public domain. Data derived from share-alike sources is offered under CC BY-SA 4.0.
- **GoLearn data** (`/go/`): see `/go/app/THIRD-PARTY-NOTICES.md` and `/go/review/THIRD-PARTY-NOTICES.md`.

Greek outside the New Testament and all the Latin are analysed automatically and may be wrong in places; the pages say so.
